- Privacy, terms, 404, SEO metadata, sitemap and robots.txt
- GitHub Pages `CNAME` for `mbastudio.online`

## Publish with GitHub Pages
1. Create a GitHub repository (for example `mba-studio-website`).
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. In **Settings → Pages → Custom domain**, enter `mbastudio.online`.
5. At the domain DNS provider, point the apex domain to GitHub Pages and configure `www` as a CNAME to your GitHub Pages hostname.
6. Enable **Enforce HTTPS** after DNS finishes resolving.
